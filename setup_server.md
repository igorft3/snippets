# Серверный скрипт базовой настройки и защиты

Этот скрипт выполняет автоматическую настройку сервера Ubuntu, включая:

- Обновление системы и установку базовых инструментов.
- Настройку брандмауэра (UFW) для разрешения только необходимых подключений.
- Установку и настройку Fail2Ban для защиты от брутфорс-атак.
- Отключение root-доступа по SSH и настройку таймаутов.
- Активацию автоматических обновлений безопасности.
- Базовую защиту (скрытие версии ядра, отключение IPv6, защита от SYN-флудов).

## Использование

1. Скачайте репозиторий и запустите скрипт одной командой:
   ```bash
   git clone -b cheklistServer https://github.com/igorft3/snippets.git && cd setup-server && chmod +x setup_server.sh && sudo ./setup_server.sh
   ```
